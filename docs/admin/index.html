案件

    実際にあった接客を1件ずつ登録する場所です。

    接客の書き起こしを貼るか、動画ファイルを読み込むと、AIが「なぜそう言ったのか」を聞く質問を作ります。
    その回答が、「基準をつくる」でエースの判断基準になります。

    書き起こし
    MP4などの動画をそのまま読み込めます。分割された録音は複数まとめて選べます（ファイル名順に処理して1つの書き起こしにまとめます）。ブラウザ内で音声だけを取り出し、無音を詰めて10分ずつに分けて書き起こします。音声は書き起こし後に破棄され、保存されません。数十時間をまとめて処理する場合は tools/extract-audio.sh を使ってください。

    書き起こしに「店員：」「客：」が付いていないと、転換点の検出精度が落ちます。先に整えてください。

      この判断基準で作ったロープレモード

        削除すると受講者の一覧から消えます。実施済みの記録は残ります。

        商品マスタ

        ロープレでお客様が持ち込む品物です。シナリオに付けた品物がそのまま出ます。付けていなければカテゴリから1点が選ばれます。 状態と正解の買取額は実施ごとに決まり、受講者には採点が終わるまで見えません。

        買取率は「美品の状態で、新品価格の何％で買い取るか」です。ロレックスや終売の酒は100を超え、 量販の家電やファッションジュエリーは10〜20になります。ここが実際の相場とずれると正解額もずれます。

        セルをそのまま書き換えられます。欄を離れると保存されます。

        まとめて取り込む（Excelから貼り付け）

        1行1件、カテゴリ / ブランド / 型番 / 商品名 / 新品価格 / 買取率% / 備考 の順。 タブ区切り（Excelからの貼り付け）かカンマ区切りにしてください。スペース区切りは読めません。
        足すだけです。いま入っている商品は消えません。同じ商品（ブランド＋型番＋商品名）は飛ばします。

        正解額の計算を確かめる

        商品と状態を選ぶと、その組み合わせでの正解額が出ます。買取率を直す前後の確認に使ってください。

        ブランド・用語マスタ

        書き起こしの精度向上と、表記揺れの統一に使われます。1行1件、正式表記 = よくある誤り1, 誤り2 の形式。 誤りが無ければ正式表記だけでも構いません。Excelから貼り付けられます。 ここに載っている語だけが自動で直され、載っていない固有名詞は触りません。

        入れておくと、書き起こしが標準語に直されるのを防ぎます。ロープレのお客様も同じ言葉づかいで話します。 方言そのものが判断基準の材料になるため、標準語に均されると本人の言葉が失われます。

        スタッフ（個人コード）

        個人コードで、見える範囲と触れる範囲が決まります。
        受講者…ロープレと自分の記録だけ／指導者…①接客を集める・会社全員の記録／管理者…③統合とマスタ編集、スタッフ管理

        パスワードは会社で共通です。個人コードは本人確認ではなく、見せる範囲の切り分けだと考えてください。

        権限を変えると、その人は一度ログアウトされます（次のログインから新しい権限になります）。

        会社

        実施記録は会社ごとに必ず分かれます。教材（案件・判断基準・モード・商品・用語）は 「ナレッジ空間」が同じ会社どうしで共有されます。2社で同じ教材を使い、記録は混ぜない、という運用がこれになります。

        既にある会社コードを入れると、名前とパスワードの変更になります。 パスワードを変えると、その会社の全員がログインし直しになります。

        接続

        練習画面と同じ設定を使います。片方でログインすれば、もう片方も入れます。

        取り込みの調整

        音声ファイルを読み込むときの処理です。既定のままで大半は動きます。素材に合わない場合だけ触ってください。

        共有トークンで入る（従来の方法）

        会社をまだ1つも作っていない段階では、こちらで入って会社とスタッフを登録します。この入口の管理者だけは、どの会社のスタッフも操作できます。

        ロープレモードを作る

        選んだ品物を全部まとめて持ってきます（「バッグと財布」のような持ち込み）。 何も選ばなければ、上のカテゴリから実施ごとに1点がランダムで選ばれます。
        どちらの場合も受講者には採点まで品物が見えません。モード名に品物名を入れると意味が無くなるので注意してください。
